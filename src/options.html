Behaviour & AI

The key is stored only in this browser and sent only to the provider you picked (DeepSeek or Anthropic). When a session reaches the context limit it is summarized into memory and a new session starts.

What the usage metrics contain

Sent (only when "Share anonymous usage metrics" is On): a random install id, extension version, browser version, the job site's hostname (no page path), detected framework and ATS, number of fields found/filled, the field types filled (e.g. "email"), question labels it couldn't match, fill and AI timings, AI provider/model, and error messages. Never sent: profile values, what was typed into forms, AI answers, API keys, resume or cover letter, full URLs.
